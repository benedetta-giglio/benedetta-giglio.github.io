# Handstand physics

Portfolio of articles on the physics and dynamics of handbalancing.

## Add a new article
Create a file in `_posts/` named `YYYY-MM-DD-title.md` that starts with:

    ---
    layout: post
    title: "Your title"
    date: YYYY-MM-DD
    ---

Equations: inline `\\( ... \\)`, display `$$ ... $$` (blank line before and after).
Images go in `assets/img/`.

## Python models
Scripts live in `python/`. Install the dependencies with `pip install -r python/requirements.txt`.
